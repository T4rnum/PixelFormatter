# Changelog

## 0.1.0 — Working preview

- Local image processing with three sampling methods, alignment controls, optional denoising, and binary transparency.
- Automatic and imported palettes, direct edits, merges, palette locking, and undo/redo.
- Synchronized previews, sampling grid, RU/EN interface, and original procedural examples.
- Indexed PNG export at native and enlarged sizes.
- Typed worker protocol, bounded processing caches, stale-result protection, unit/browser tests, and CI.

Real-input artistic review and a public hosted demo remain planned milestones.
